# 影の刃 — Shadow Blade

アサシンクリード風の 2D 横スクロール・ステルスアクション。TypeScript と素の Canvas2D だけで作っています（ゲームエンジン・画像・音声ファイルなし。絵はすべてコード描画、音は WebAudio で合成）。

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

初めて「はじめる」を選ぶと、まず **教団の訓練場**（チュートリアル）で移動・登攀・信仰の跳躍・暗殺・群衆・パリィ・コンボ・鷹の目・道具を 1 つずつ練習します。訓練中は倒れてもすぐに立ち直ります。Esc のポーズから「訓練を飛ばす」こともでき、タイトルの「訓練」からいつでもやり直せます。

音量はタイトルまたはポーズの **設定** から、全体・BGM・効果音を 0〜10 で個別に調整できます（M でミュート）。設定はセーブデータとは別に保存されるので、「最初から」を選んでも消えません。

その後、3 つの地区（スラム街 → 大市場 → 貴族街）からなる街に潜む **6 人の標的** を、好きな順番で暗殺してください。全員倒すとクリアで、結果画面にランクが出ます。

- **ステルス**：衛兵には視界（扇形）があり、入ると「？」ゲージが溜まって満タンで戦闘になります。フリーランや登攀中は見つかりやすく、弓兵は屋根の上の侵入者に厳しいです。
- **紛れる・隠れる**：歩いて市民の集団（3 人以上）に入ると群衆に紛れます。干し草には F で隠れられ、高所から飛び込めば「信仰の跳躍」で無傷です。
- **物音・死体**：フリーランの足音や戦闘音で衛兵が寄ってきます。死体を見つかると地区全体の警戒が強まり、戦闘が続くと応援が駆けつけます。
- **暗殺**：気づいていない敵の背後、真上からの落下、干し草の中から J で一撃。煙玉で足止めした敵も暗殺できます。
- **戦闘**：J の 3 段コンボ、K の防御（攻撃直前ならパリィ → J でカウンター）、L の回避。赤く光る重い攻撃は防御できません。
- **探索**：屋根の上に古文書が 30 枚。集めると体力・ナイフ所持数・登攀速度などが強化されます。
- **隠れ家**：各地区に 1 つ。入ると体力と装備が回復し、死んだときの復活地点になります。進行は自動で保存されます（localStorage）。

## 操作

| キー | 動作 |
|---|---|
| A / D | 移動（歩くと静か） |
| Shift + 移動 | フリーラン（速いが目立つ。屋根の端で自動ジャンプ） |
| W / S | 壁を登る・降りる（屋根の上で S：ぶら下がる / 梁から降りる） |
| Space | ジャンプ（登攀中は方向キーと同時で飛び移る） |
| J | 攻撃・暗殺 |
| K | 防御・パリィ |
| L | 回避ロール |
| I / O | 投げナイフ / 煙玉 |
| E（長押し） | 鷹の目（標的＝金、敵＝赤、文書＝青） |
| F | 干し草に隠れる・出る |
| Esc / M | ポーズ（設定・訓練を飛ばす）/ ミュート |

## 開発

```bash
npm run typecheck   # tsc
npm run lint        # eslint
npm test            # vitest（ロジックのユニットテスト）
npm run e2e         # playwright（ビルドして起動 → 操作するスモークテスト）
npm run build       # dist/ に静的ファイルを出力
```

`?debug` を付けて開くと `window.__game` からワールドの状態を参照できます。

### 構成

```
src/
  core/      入力・カメラ・数学・乱数
  world/     タイルマップ、街の生成（city.ts）、視線判定、World（全体の更新）
  entities/  プレイヤー・衛兵・市民・飛び道具
  systems/   物理、パルクール、ステルス（視界/発見）、衛兵AI、戦闘、セーブ/強化
  render/    背景、建物、人物（関節角度による手続きアニメ）、鷹の目、HUD、パーティクル
  audio/     効果音シンセ、BGM シーケンサー
  scenes/    タイトル・ゲーム・リザルト
```

ゲームロジック（`systems/`・`entities/`・`world/`）は DOM に依存しないので、Vitest から `World` を直接動かしてテストしています（`tests/helpers.ts`）。
