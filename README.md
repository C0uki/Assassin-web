# 影の刃 — Shadow Blade

アサシンクリード風の 2D 横スクロール・ステルスアクション。TypeScript と素の Canvas2D だけで作っています（ゲームエンジン・画像・音声ファイルなし。絵はすべてコード描画、音は WebAudio で合成）。

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

初めて「はじめる」を選ぶと、まず **教団の訓練場**（チュートリアル）で移動・登攀・信仰の跳躍・暗殺・群衆・パリィ・コンボ・鷹の目・回復・道具を 1 つずつ練習します。訓練中は倒れてもすぐに立ち直ります。Esc のポーズから「訓練を飛ばす」こともでき、タイトルの「訓練」からいつでもやり直せます。

音量はタイトルまたはポーズの **設定** から、全体・BGM・効果音を 0〜10 で個別に調整できます（M でミュート）。設定はセーブデータとは別に保存されるので、「最初から」を選んでも消えません。

その後、3 つの地区（スラム街 → 大市場 → 貴族街）からなる街に潜む **6 人の標的** を、好きな順番で暗殺してください。6 人を倒すと街の東の端に **騎士団の門** が開き、F で入ると黒幕 **騎士団総長モルディウス** との決戦です。総長を倒すと結末が流れ、結果画面にランクが出ます。

- **決戦**（体力 45、3 段階。負けると決戦の最初から。「街へ戻る」で準備し直すこともできます）
  1. **剣の一騎打ち**：白く光る 3 連撃はパリィ → J のカウンター。赤く光る重い一撃と突進突きは防げないので L で回避。
  2. **鐘楼の上から**：総長はバルコニーに跳び上がって短剣を投げ、手下が波のように押し寄せます。手下を片づけた合間に、隣の家から鐘楼の壁に移って真上から空中暗殺すると大きく削れます。
  3. **影武者と群衆**：煙とともに総長は群衆に紛れ、そっくりな影武者が 2 人現れます。鷹の目で金色に光るのが本物です。影武者を斬ると煙になって消え、本物が群衆から飛び出して突いてきます。気づかれずに背後から暗殺すれば一度に大きく削れます。

- **敵**：衛兵・精鋭（盾と重い一撃）・弓兵（屋根の上）に加えて、
  - **追跡者**：壁を登り屋根の隙間も跳んで追ってくる
  - **重装兵**：パリィが効かず怯まない。登れないので屋根に逃げるか暗殺で
  - **番犬**：見張りに連れられ、干し草や群衆に隠れていても近くにいると嗅ぎつけて吠える
  奥の地区ほど手強い敵が増えます。
- **ステルス**：衛兵には視界（扇形）があり、入ると「？」ゲージが溜まって満タンで戦闘になります。フリーランや登攀中は見つかりやすく、弓兵は屋根の上の侵入者に厳しいです。
- **紛れる・隠れる**：歩いて市民の集団（3 人以上）に入ると群衆に紛れます。干し草には F で隠れられ、高所から飛び込めば「信仰の跳躍」で無傷です。
- **物音・死体**：フリーランの足音や戦闘音で衛兵が寄ってきます。死体を見つかると地区全体の警戒が強まり、戦闘が続くと応援が駆けつけます。
- **暗殺**：気づいていない敵の背後、真上からの落下、干し草の中から J で一撃。煙玉で足止めした敵も暗殺できます。
- **戦闘**：J の 3 段コンボ、K の防御（攻撃直前ならパリィ → J でカウンター）、L の回避。赤く光る重い攻撃は防御できません。
- **探索**：屋根の上に古文書が 30 枚。集めると体力・薬やナイフの所持数・登攀速度などが強化されます。
- **落下**：約 10 タイルより高く落ちるとダメージ（最大 4）。着地の直前に L で受け身をとれば無傷です。フリーランの自動ジャンプは、届く足場・干し草・掴める壁があるときだけ跳び、それ以外は屋根の端で止まります。
- **回復**：薬を最大 2 個持ち歩き、H で飲むと体力 +4（飲む間の 0.6 秒は無防備で、斬られると中断）。路地に落ちている食べ物は触れるだけで体力 +2。街の回復アイテムは取ってから 90 秒で復活し、倒した衛兵がときどき食べ物を落とします。薬は隠れ家で補充できます。
- **隠れ家**：各地区に 1 つ。入ると体力と装備が回復し、死んだときの復活地点になります。進行は自動で保存されます（localStorage）。

## 操作

| キー | 動作 |
|---|---|
| A / D | 移動（歩くと静か） |
| Shift + 移動 | フリーラン（速いが目立つ。屋根の端で自動ジャンプ） |
| W / S | 壁を登る・降りる（屋根の上で S：ぶら下がる / 梁から降りる） |
| Space | ジャンプ（登攀中は方向キーと同時で飛び移る） |
| J | 攻撃・暗殺 |
| K | 防御・パリィ |
| L | 回避ロール（空中で着地直前に押すと受け身） |
| H | 薬を飲む |
| I / O | 投げナイフ / 煙玉 |
| E（長押し） | 鷹の目（標的・総長＝金、敵＝赤、文書＝青） |
| F | 干し草に隠れる・出る／騎士団の門に入る |
| Esc / M | ポーズ（設定・訓練を飛ばす）/ ミュート |

## 開発

```bash
npm run typecheck   # tsc
npm run lint        # eslint
npm test            # vitest（ロジックのユニットテスト）
npm run e2e         # playwright（ビルドして起動 → 操作するスモークテスト）
npm run build       # dist/ に静的ファイルを出力
```

`?debug` を付けて開くと `window.__game` からワールドの状態を参照できます。

### 構成

```
src/
  core/      入力・カメラ・数学・乱数
  world/     タイルマップ、街の生成（city.ts）、視線判定、World（全体の更新）
  entities/  プレイヤー・衛兵・市民・飛び道具
  systems/   物理、パルクール、ステルス（視界/発見）、衛兵AI、総長戦（boss.ts）、戦闘、セーブ/強化
  render/    背景、建物、人物（関節角度による手続きアニメ）、鷹の目、HUD、パーティクル
  audio/     効果音シンセ、BGM シーケンサー
  scenes/    タイトル・ゲーム・結末・リザルト
```

ゲームロジック（`systems/`・`entities/`・`world/`）は DOM に依存しないので、Vitest から `World` を直接動かしてテストしています（`tests/helpers.ts`）。
